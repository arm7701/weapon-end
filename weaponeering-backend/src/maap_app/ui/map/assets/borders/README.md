# Map Border Assets

Local GeoJSON boundaries bundled for the Cesium map **Borders** layer.

| File | Source | Description |
| --- | --- | --- |
| `thailand_adm0_simplified.geojson` | geoBoundaries (THA ADM0) | Simplified Thailand country outline used by the map border toggle |

These files are loaded offline from the desktop app package. Do not replace with live map services.
